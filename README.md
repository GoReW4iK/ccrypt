# CCrypt

Консольная утилита на C++ для шифрования и расшифровки текстовых файлов с реализацией классических алгоритмов.

## Поддерживаемые алгоритмы

- **Binary** — перевод текста в двоичное представление и обратно (без ключа).
- **Caesar** — шифр Цезаря (числовой ключ).
- **Scytall** — шифр Скитала (числовой ключ).
- **Affine** — аффинный шифр (без ключа).
- **Atbash** — шифр Атбаш (без ключа).
- **Tritemius** — шифр Тритемия (ключ-слово).
- **XOR** — побитовое XOR-шифрование (ключ-слово; для корректной работы длина ключа должна соответствовать тексту или повторяться без искажений).
- **DES** — алгоритм блочного шифрования DES (ключ-слово).
- **RSA** — асимметричное шифрование с возможностью ввода готовых ключей `(n, e)` / `(n, d)` или генерации новой пары простых чисел в диапазоне `1000..9999`.

## Работа с файлами

Перед запуском убедитесь, что в корне проекта (или рабочем каталоге программы) находятся следующие файлы:

- `data.txt` — исходный текст для шифрования;
- `encrypted.txt` — зашифрованные данные (сюда записывается результат и отсюда же читаются данные при расшифровке);
- `decrypted.txt` — результат расшифровки.

## Сборка и запуск

Проект рассчитан на **Windows** и настроен под **Visual Studio** (`Custom.sln`, `Custom.vcxproj`, toolset `v143`).

1. Откройте `Custom.sln` в Visual Studio.
2. Выберите конфигурацию **Release** (в ней корректно и стабильно работает модуль DES).
3. Соберите решение и запустите `Custom`.
4. Выберите нужный алгоритм и режим работы (`Encrypt` / `Decrypt`) в меню.
